# Maidaan

Nagpur-first verified turf booking experience. This repository currently contains the mobile-first player web prototype covering home discovery, turf detail and scorecard, live slot selection, transparent UPI checkout, split pay controls, and booking confirmation.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

## Prototype data policy

All availability, ratings, field notes, prices, verification dates, and photos in this build are sample prototype content. Generated demo images are explicitly labelled and must be replaced with dated scout photographs before any listing is published.
